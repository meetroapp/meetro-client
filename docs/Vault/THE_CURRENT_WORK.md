# The Current Work

The current work is the only reliable anchor in Meetro.

People do not switch between disconnected functions.
They remain inside one work relationship while responsibilities change.

## Principle

The current work can hold multiple responsibilities over time:

- discovery
- communication
- scheduling
- proposal
- payment
- completion
- closure
- history

But it should never be replaced by those responsibilities.

## What the Anchor Is

- A project, job, or request with a person attached.
- A shared status that changes through lifecycle.
- A continuity identity that can be projected in Work Center, History, Discovery, and Conversations without contradiction.

## What the Anchor Is Not

- A dashboard card only.
- A role-specific filter only.
- A temporary surface state.
- A navigation destination.

## Homeowner Anchor

The homeowner remains inside the same request work from first contact through review, visit, and memory.

Completion evidence and follow-up should be part of the same arc, not a new isolated domain.

## Professional Anchor

The professional remains inside the same job through Evaluation → Proposal → Work → Completion → Closure.

The next tool can be conversation, schedule, billing, or handoff.

The person should not feel that changing tool means leaving the job.

## Alignment Contract

Every surface should be answerable by the same anchor:

- What is this work?
- What matters now?
- What changes next?
- What is completed, and what remains?
