# Meetro Language Standard

## Purpose

Meetro language should make each surface feel natural for the device without changing the product meaning.

Mobile labels may be short.

Workspace and page titles carry the full meaning.

Navigation is reserved for durable platform destinations.

Home and Dashboard surfaces launch actions.

## Mobile Labels

Mobile bottom navigation should stay compact and permanent:

- Home
- Work
- Chat
- Moments
- Profile

These labels are doorways, not instructions.

The destination page should provide the complete identity.

## Workspace Titles

Short mobile labels map to fuller page language:

- Chat -> Communication Center
- Moments -> Meetro Moments
- Work -> Work Center
- Timeline -> Meetro Moments

Do not use Timeline publicly for Meetro Moments.

Do not use Messages as the primary page title when the surface represents the full communication workspace.

## Navigation Ownership

Home is the launch point for actions.

Navigation is the doorway to destinations.

Request Service is an action. It belongs on Home and contextual request surfaces.

Leads is an operational work queue. It belongs on Business Dashboard and Work Center shortcuts.

Request Service and Leads should not appear as mobile bottom-navigation destinations.

## Desktop Language

Desktop has more room for workspace destinations.

Desktop navigation may use fuller destination language such as:

- Home
- Work Center
- Communication
- Meetro Moments
- Properties
- Relationships
- Community
- Profile / Account

More room should clarify destinations, not duplicate shortcuts.

## Guardrails

Do not turn action shortcuts into permanent navigation.

Do not rename workflows when only the label should adapt.

Do not remove existing functionality when removing a shortcut from navigation.

Do not use vague labels when a workspace needs a clear title.

Do not use Timeline, Feed, Posts, Wall, or Activity for Meetro Moments.

## Success Standard

Users should understand where they are going before they tap.

Mobile should feel simple.

Desktop should feel like platform workspace navigation.

No workflow should disappear because a shortcut moved to its proper home.
