# Work Center Attention Hierarchy

## The Discovery

Work Center should answer more than “what page is available”.
It should answer what deserves immediate attention in the current professional workflow.

Attention is the ordering of responsibility, not a list of all available features.
This document sets a consistent rhythm for how urgency is understood across the workday.

## Immediate Attention

Immediate Attention are responsibilities that require action now.

- Emergency
- Current Job
- Arrival
- Customer Waiting
- Current Conversation
- Record Evaluation
- Start Work
- Complete Work
- Generate Invoice

Immediate Attention should always override every other category.

## Today's Attention

Today's Attention supports today’s workflow so work can be prepared and sequenced.

- Today's Schedule
- Opportunities
- Pending Quotes
- Follow-ups
- Today's Tasks

These receive focus after Immediate Attention is clear.

## Reference Attention

Reference Attention supports understanding and reflection.

- Revenue
- Job History
- Reports
- Business Metrics

Reference information should support decisions already in motion, not displace active work.

## Time Flow

Attention changes through the day as responsibility changes.

### Morning

- Primary:
  - Today's Schedule
  - First Customer
  - Preparation

### Travel

- Primary:
  - Current Customer
  - Navigation
  - Conversation
  - Arrival

### On Site

- Primary:
  - Evaluation
  - Proposal
  - Documentation
  - Work

### Completion

- Primary:
  - Completion
  - Invoice
  - Customer Walkthrough
  - Payment

### End of Day

- Primary:
  - Revenue
  - History
  - Follow-up
  - Business Review

The interface should shift emphasis as this day rhythm changes, while staying on the same professional work.

## Focus Transition

Work remains the anchor; attention changes.

Evaluation
↓
Proposal
↓
Approval
↓
Work
↓
Completion
↓
Invoice
↓
History

The user should feel they are still inside the same work, with each responsibility passing naturally to the next.

## Relationship to Focus Workspace

Focus Workspace does not move work.
It changes emphasis.

The work remains the anchor.
Attention changes by responsibility.
The work context stays continuous.

## Preserve

- Do not modify UI
- Do not modify navigation
- Do not modify routing
- Do not modify lifecycle
- Do not modify storage
- Do not modify projections
- Do not modify current behavior

This phase defines architecture and attention truth only.

## Constitutional Principle

Attention should follow the work.
Not the menu.
Not the page.
Not the feature.
The current work deserves attention before everything else.

The Lantern stays lit.
